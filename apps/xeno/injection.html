End-to-end

Injection flow — 16 steps

reconstructed from strings + exports
  1. 1
    Step 1

    Launch & load

    main.js spawns BrowserWindow, loads build/index.html. preload.js injects contextBridge APIs. On app.whenReady → initializeXeno().

  2. 2
    Step 2

    Load native layer

    xenoAddon = require('xeno.node'). xeno.node calls LoadLibraryW on Xeno.dll (path in XENO_DLL_PATH env or process.resourcesPath/public/Xeno.dll).

  3. 3
    Step 3

    Boot Xeno.dll

    xeno.node resolves and calls Xeno.dll::Initialize(debug). Xeno.dll spins up 3 threads: XenoServer (httplib on localhost:auto), Caching (RBXBytecode/MFlags/ClientInfo cache), BytecodePatchWatcher.

  4. 4
    Step 4

    Fetch offsets

    Caching thread downloads https://x3no.pages.dev/ep.zst.enc via libcurl+OpenSSL, decompresses zstd, decrypts, parses per-Roblox-version offset table into RBXClient. On failure: pastebin fallback.

  5. 5
    Step 5

    User clicks Attach

    renderer invokes 'xeno-attach' → ipcMain → xenoAddon.attach() → Xeno.dll::Attach().

  6. 6
    Step 6

    Open Roblox process

    EnumProcesses → find RobloxPlayerBeta.exe. OpenProcess with PROCESS_VM_READ|WRITE|OPERATION|QUERY_INFORMATION. If opening fails due to privilege elevation, logs 'Please run Xeno as administrator'.

  7. 7
    Step 7

    Resolve DataModel

    Walk static offsets → DataModel → CoreGui → RobloxGui → Modules. Logs 'Could not find RobloxGui->Modules. Going back to in-game check...' on timing issues.

  8. 8
    Step 8

    Hijack translation

    Locate the locale translation ModuleScript inside RobloxGui->Modules (used on every UI refresh). Record 'Intercepted translation module @0x...'

  9. 9
    Step 9

    Compile bootstrap

    Xeno.dll's embedded Luau compiler produces bytecode for the client-init script. The bootstrap wraps the user's script in `getfenv().Xeno` env + Instance.new('LocalScript') to expose the executor API.

  10. 10
    Step 10

    Patch bytecode

    VirtualAllocEx + NtWriteVirtualMemory overwrite the translation module's bytecode field with the bootstrap bytecode. Writes the new bytecode blob + updates the ModuleScript's bytecode pointer.

  11. 11
    Step 11

    Trigger refresh

    Force a window / locale refresh so Roblox re-requires the translation module and runs the patched bytecode. If window won't refresh: 'Using RefreshRBXWindowV2...'

  12. 12
    Step 12

    Client bootstrap pings

    Patched bytecode (running inside Roblox) connects back to http://localhost:<port>/attach, Xeno.dll server registers this RBXClient and marks it attached.

  13. 13
    Step 13

    Watch loop

    BytecodePatchWatcher polls the module's bytecode field. If Roblox overwrites (e.g., re-fetches translations), re-patches. If 'threshold reached', restores original to prevent crash.

  14. 14
    Step 14

    Autoexec

    Successful attach fires HandleAutoExecute(): iterates %LOCALAPPDATA%/Xeno/autoexec/, runs each via Execute path.

  15. 15
    Step 15

    User Execute

    renderer sends script text → execute flow: Luau compile → RBXClient server endpoint → bootstrap in-game picks it up → run inside LocalScript env.

  16. 16
    Step 16

    Multi-client

    Each Roblox window becomes its own RBXClient. GetClients returns them; UI shows per-client attach state + lets you execute on all or one.

Primitive

The actual cross-process writes

Xeno is not a classical DLL injector. The Xeno.dll binary runs inside the Electron process. It never gets loaded into RobloxPlayerBeta.exe. Instead, it:

  1. OpenProcess on Roblox to get a handle with VM-read/write/operation rights.
  2. Walks static offsets to locate DataModel → CoreGui → RobloxGui → Modules and finds the locale translation ModuleScript (chosen because it's re-run on every UI refresh and is always present).
  3. VirtualAllocEx in Roblox's address space for a new bytecode region.
  4. NtWriteVirtualMemory (resolved dynamically via GetProcAddress on ntdll) copies the Luau-compiled bootstrap bytes into that region.
  5. Overwrites the ModuleScript's bytecode pointer + size fields so Roblox's own VM runs the new blob on next require/refresh.
  6. The in-game bootstrap, now executing, connects to http://localhost:<port>/ served by Xeno.dll, becoming an attached RBXClient.

Bootstrap

The Luau script the executor runs before yours

Lifted verbatim from Xeno.dll .rdata. The Xeno table is populated at bootstrap by the executor and exposes the usual loadstring, getrawmetatable, hookfunction, writefile, etc. The setfenv + LocalScript trick makes every subsequent script global resolve to a real Instance so unmodified scripts work.

return function(...)
  for i,v in getfenv().Xeno do getfenv(0)[i]=v end
  local e={}
  setmetatable(e, {__index = getfenv().Xeno})
  setfenv(1,e)
  local s=Instance.new('LocalScript')
  getfenv(1).script=s
  setfenv(0, getfenv(1))
  -- user script body spliced here
end

What Xeno logs during Attach

Happy path

  • • Attempting to retrieve RBXClient data...
  • • Successfully retrieved RBXClient data (Primary)
  • • RBXClient data resource decompression failed (It is likely corrupted). Using secondary endpoint
  • • Successfully retrieved RBXClient data from endpoint (Secondary)
  • • Failed to retrieve RBXClient data due to an exception: {}
  • • Attaching in-game using translation module.
  • • Attach is taking longer than expected... (I hate you {})
  • • Did not receive the success ping from client. Using RefreshRBXWindowV2...

Offsets / version mismatch

  • • Offsets for version "{}" points to version "{}" with same offsets
  • • Offsets for version "{}" points to "{}", but it is missing or invalid.
  • • Offsets for version "{}" not found. Using offsets from default version: {}. Please report this to me (Rizve)
  • • {} offsets are invalid and almost crashed Xeno. Please update your client to the latest supported version!
  • • RBXClient data is missing offsets for "{}" and the 'default' offsets index

Execute errors

  • • [{}]: Failed to compile (this is a problem with your script): {}
  • • [{}]: Could not verify that the execution module has changed. Script may not be executed! (Your Roblox client cannot keep up and may be overloaded)
  • • [{} ({})][::Loadstring]: DataModel address is invalid
  • • [{} ({})][::Loadstring]: Could not find the ModuleScript with the given name "{}"
  • • [{} ({})][::HandleAutoExecute]: Auto Execute directory is invalid
  • • [{} ({})][::HandleAutoExecute]: Executed {} script(s) from autoexec directory
  • • [SetScriptBytecode:{}] Client not found

Admin / safety

  • • Failed to open the Roblox client process because it is running with administrator privileges. Please run Xeno as administrator or restart Roblox without administrator privileges.
  • • Blocked attempt to write file with extension '{}' ("{}") from a script you executed.
