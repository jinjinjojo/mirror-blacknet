01
backend leaks

What the client reveals about the server side

Public endpoints
backendConfig.js hints at /hot-wallet. Likely also /api/user/*, /api/rounds/*, /api/leaderboard, /api/provablyFair/verify.
WebSocket origin
Socket.io on the main domain or a sub-origin (ws:// in dev, wss:// in prod). Join without auth is likely allowed for read-only room observation (common in gambling sites to show rounds to non-auth visitors).
Local overridable config
localStorage key `api-assign:backend` lets any JS context on the page redirect backend URL + API URL. Any XSS or malicious extension = full MITM on that user's session.
Build commit SHA leak
e2e705c2d20718926e9d73a490458f2da71d81ba embedded in every chunk's Sentry init. If the repo is a public GitHub, this is the exact revision auditors can read.
Full fairness code shipped
generatePrices + seedrandom + commit/reveal UI are all in the client. Anyone can offline-verify any past round. Also means the house-side implementation must match this bytecode exactly — any mismatch is itself a client-visible finding.
Round history is public
useDrawingHistory / history socket events pull past-round data without auth. Lets any observer compute price-array hashes across rounds for seed-collision detection (A2 above).
Pixi + sprite sheets
Game visuals shipped as sprite sheets. Rev-eng-able but not security-relevant.
02
dev flags

Debug surfaces reachable from the browser

localStorage
`DEV_<flag>` keys read at bundle init time. Setting them from the console enables dev-only UI (debug panels, verbose logging, state inspectors).
Query params
`?dev_<flag>=1` URL params parsed by `new URL(window.location.search).get('dev_...')` — several debug UIs enable from URL.
Implication
Users can poke around for undocumented flags by probing common names (`DEV_SHOW_SEED`, `DEV_SHOW_POOL`, `dev_debug`, `dev_god`). Any leaked flag that reveals in-flight state would be an immediate finding.

Common dev flags to probe: DEV_DEBUG, DEV_SHOW_SEED, DEV_SHOW_POOL, DEV_FORCE_PHASE, ?dev_debug=1, ?dev_god=1. Any flag that renders in-flight state is immediate HIGH severity.
