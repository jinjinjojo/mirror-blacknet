scope

What we did and didn't do

Rules followed

  • › No accounts created, no logins, no wallets connected
  • › No trades, subscriptions or purchases
  • › On-chain data read only through public RPC and explorer APIs
  • › Web apps observed in a clean browser profile; scripts parsed, never run outside the page
  • › Every number traces to a captured artifact or a cited source

Limits

  • › On-chain bytecode shows how a bot executes, not how it decides. Searcher strategy runs on private servers.
  • › Opcode counts come from a linear sweep that also walks data bytes. Treat them as approximate; e.g. 0xff bytes in data would read as SELFDESTRUCT and are excluded here.
  • › Function names come from a public signature database and can be collisions; argument types come from EVMole inference.
  • › Figures for private firms (Renaissance, Citadel Securities, XTX) are reported, not audited. Jane Street's India figures are interim regulator allegations.
  • › The fee recipient 0x4838…5f97 is publicly labelled Titan Builder by block explorers; we did not verify the label independently.
  • › Web captures show the client. Server-side logic, referral percentages and Holly's full track record were not visible without logging in, and we did not log in.
