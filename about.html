ABOUT THIS CONSOLE

Operator console for people who care how shipped software is actually built. Every claim pinned to a byte in a shipped artifact. Nothing executed. Nothing scraped at scale. Nothing proxied through a backend you can't see.

RULES OF ENGAGEMENT
//01//What this is

Static reverse-engineering reports (dossiers) for native, Electron, and web-wrapped software. Each dossier is produced with disciplined pipeline: unpack, inspect, decompile named exports, trace end-to-end flow, publish with evidence citations.

In-browser operator tools that never phone home.

Curated advisory feed and long-form writeups.

//02//What this is not

Not an exploit shop. Not a cheat distribution site. Not a cracked-software index.

Dossiers describe how software works. They are not instructions to attack it.

Nothing on this site runs the targets it analyzes.

//03//Reporting problems

Found a factual error in a dossier? Open an issue on the repo. Have a target you want on the queue? Same place.
